# Dokumentasi SIGAP Smart Bin

Folder ini memuat spesifikasi kebutuhan, rancangan perangkat lunak, konsep sistem, RAB, dokumen sumber, dan aset visual SIGAP Smart Bin.

## Dokumen utama

- [SIGAP_PRD_v1.0.md](SIGAP_PRD_v1.0.md): Product Requirements Document.
- [SIGAP_SDD_v1.0.md](SIGAP_SDD_v1.0.md): Software Design Document.
- [SIGAP_Smart_Bin_Konsep_dan_RAB_v0.8.md](SIGAP_Smart_Bin_Konsep_dan_RAB_v0.8.md): konsep sistem, detail alat, rencana eksperimen sensor, dan RAB.

## Operasional dan verifikasi

- [Konfigurasi FIS](fis-configuration.md): lima input, himpunan, rule, centroid, dan batas buktinya.
- [Kurva NH3 MQ-135](mq135-winsen-nh3-curve.md): digitasi Winsen v1.6 Figure 3, domain, dan batasnya.
- [Kebijakan prototype](prototype-operation.md): latest-only, tanpa backlog, tanpa backup SD.
- [Kalibrasi default](calibration-defaults.md): profil pabrik, presedensi, dan batas bukti.
- [Analisis web dan sensor live](web-derived-research.md): provenance `WEB_DERIVED_TEST_ONLY`, ppm, dan validitas.
- [Pengiriman arsip live](live-archive-delivery.md): jalur pengiriman dan pemulihan.
- [Simulasi sensor firmware](firmware-sensor-simulation.md): mode simulasi dan batasnya.
- [Checkpoint integrasi sensor](task9-current-status.md): status terkini, bukan penerimaan fisik.

## Aset dan sumber

- [SIGAP_Asset_Pack_Complete_v0.6](SIGAP_Asset_Pack_Complete_v0.6/README.md): aset UI, diagram, ilustrasi, perangkat, lokasi, dan identitas visual.
- `SIGAP_MD_Documents_v1.0/`: salinan hasil ekstraksi PRD dan SDD.
- `SIGAP_Apps_Source_of_Truth_v0.3.docx`: sumber rancangan aplikasi.
- `SIGAP_Smart_Bin_Konsep_dan_RAB_v0.8.docx`: sumber konsep sistem dan RAB.
- `Proposal Penelitian Tempat Sampah - M. Iqbal Ardimansyah.docx`: dokumen proposal penelitian.
