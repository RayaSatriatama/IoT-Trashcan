# SIGAP application screenshots

Desktop and mobile captures are divided into normal viewport-sized frames in scroll order, so the full interface can be reviewed without an unrealistically tall image. The captures use synthetic local fixture data for Gedung A / Biru, Gedung B, Gedung E, Lapangan Olahraga, Parkiran Motor, Parkiran Mobil, Masjid As-Sakinah, and Asrama. They do not represent production telemetry.
